# Auditi Licensing

Auditi adopts a dual-license model to balance open-source freedom with sustainable development.

## Summary

| Component | License | Description |
| :--- | :--- | :--- |
| **SDK** (`sdk/`) | **MIT** | Fully open source. Use, modify, and distribute freely. |
| **Core Backend** | **MIT** | Core infrastructure and basic features. |
| **Core Frontend** | **MIT** | Core UI pages and api client. |
| **Enterprise Features** | **BSL 1.1** | Advanced features (analytics, evaluations, etc.). Free for non-competing use. |

## What is BSL 1.1?

The **Business Source License (BSL) 1.1** is a source-available license that allows you to copy, modify, redistribute, and make non-commercial use of the code.

**You CAN:**
- Read the source code.
- Fork the repository.
- Self-host Auditi for your organization.
- Modify the code for internal use.
- Build integrations on top of Auditi.

**You CANNOT:**
- Offer Auditi as a commercial hosted service (SaaS) that competes with Auditi's paid offerings.

## Change License

On **2028-02-09** (4 years from publication), all BSL 1.1 code will automatically convert to the **Apache License, Version 2.0**.
